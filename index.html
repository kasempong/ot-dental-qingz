สรุปค่าตอบแทน OT ทันตแพทย์

อ่านไฟล์ที่ส่งออกจาก HOSxP คัดเฉพาะงานนอกเวลาราชการ คำนวณ Workload ตามบัญชีหมายเลข ๒ แล้วออกเป็นไฟล์ Excel พร้อมลงนาม

ข้อมูลผู้ป่วยจะไม่ถูกส่งออกนอกเครื่องของคุณไฟล์ HOSxP ถูกอ่านและคำนวณในเบราว์เซอร์นี้เท่านั้น ไม่มีการอัปโหลดไปยังเซิร์ฟเวอร์ใด และไม่ถูกบันทึกไว้หลังปิดหน้า สิ่งที่จำไว้ในเบราว์เซอร์มีแค่ค่าตั้งค่า เช่น อัตรา Workload และวันหยุด
1

เลือกไฟล์และทันตแพทย์

อัปโหลดไฟล์ .xlsx จาก HOSxP ได้หลายไฟล์ ระบบจะรวมให้

ลากไฟล์มาวางที่นี่ หรือคลิกเพื่อเลือก ต้องมีคอลัมน์ vstdate, vsttime, hn, ptname, doctor_name, tm_name, ttcode, fee ไฟล์จะถูกเปิดในเครื่องนี้เท่านั้น ไม่มีการอัปโหลดขึ้นอินเทอร์เน็ต
    2

    ตั้งค่าการคำนวณ

    ใช้ค่าเริ่มต้นได้เลย กดหัวข้อเพื่อดูหรือแก้ไข ค่าที่แก้จะถูกจำไว้ในเบราว์เซอร์นี้

    เวลา OT และฐานขั้นต่ำ

    เวลาเริ่มนับ OT ใช้กับวันจันทร์–ศุกร์ที่เป็นวันทำการเท่านั้น ส่วนวันเสาร์–อาทิตย์และวันหยุดราชการนับเป็น OT ทั้งวันไม่ว่าจะมาเวลาใด
    ค่าตอบแทนรายวัน = ค่าที่มากกว่าระหว่าง Workload รวมของวัน กับฐานขั้นต่ำตามประเภทวัน

    วันหยุดราชการ
    โปรดทบทวนรายการวันหยุดทุกครั้งก่อนใช้รายการนี้ใส่ไว้ล่วงหน้าจากประกาศที่มีอยู่ ครม. อาจประกาศวันหยุดพิเศษเพิ่ม และต้องเพิ่มวันหยุดของปีถัดไปเอง ตรวจกับประกาศของสำนักเลขาธิการคณะรัฐมนตรี

    บรรทัดละ 1 วัน รูปแบบ ปี-เดือน-วัน (ค.ศ.) ตามด้วยชื่อวันหยุด เช่น 2026-10-23 วันปิยมหาราช

    อัตรา Workload ตามบัญชีหมายเลข ๒

    ระบบตรวจชื่อหัตถการ (tm_name) กับกฎจากบนลงล่าง ใช้กฎแรกที่ตรง คำค้นคั่นด้วยจุลภาค = ตรงคำใดคำหนึ่ง ใช้ + = ต้องมีทุกคำ เช่น ฟันคุด+Partial Bony รายการที่ไม่ตรงกฎใดเลยได้ 0 และถูกไฮไลต์ให้ตรวจ

    ลำดับคำค้นใน tm_nameวิธีคิดอัตราไฮไลต์ให้ตรวจ

    วิธีคิด: ต่อซี่ = คูณจำนวนซี่ใน ttcode · ต่อครั้ง = คิดครั้งเดียว · ต่อ quadrant = คูณจำนวน QUADRANT · ต่อชิ้น (arch) = คูณจำนวน ARCH และคูณ fee ด้วย (ใช้กับการใส่ฟันเทียม) · Endo = คิดตามตำแหน่งฟันด้านบน
